# ML Engineering From Scratch

Hands-on implementations of machine learning, NLP, deep learning,
LLMs, and AI engineering concepts from first principles.

This repository contains my solutions to programming and AI/ML
challenges from TensorTonic.

## Topics

- Machine Learning
- Deep Learning
- NLP
- Transformers & LLMs
- PyTorch
- NumPy
- Optimization
- Computer Vision
- CUDA / GPU Programming
- Triton
- Inference Engineering
- AI Systems

## Goal

The goal of this repository is to strengthen my understanding of
AI/ML systems by implementing algorithms and core concepts from
scratch rather than relying solely on high-level libraries.

## Source

Problems are based on challenges available on TensorTonic:
https://www.tensortonic.com/problems
